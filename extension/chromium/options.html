Connect to TimeToll

Run timetoll pair in your terminal and enter the settings below. Keep timetoll run running while you use the browser.

Run timetoll apps, then switch to this browser to find its identifier. Chrome uses com.google.Chrome on macOS or chrome.exe on Windows. Thorium on macOS uses org.chromium.Thorium; replace the suggested Chrome identifier.

The extension sends the active tab URL and browser identifier to your computer once per second. TimeToll keeps URLs in memory only. No data leaves your computer.
